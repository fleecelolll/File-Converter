FILE CONVERTER

A little tool I made with AI to quickly convert common image, audio, video, archive, and script files locally on 64-bit Windows.

INSTALL

1. Download the latest release ZIP.
2. Extract the complete folder.
3. Double-click Installer.bat.
4. Press Y once to accept the Terms and bundled Tool License and approve setup.
5. Leave the setup window open until every check passes.
6. Double-click the File Converter shortcut created in the folder.

Keep the full extracted folder path at 72 characters or fewer so Windows can install the private packages reliably.

USE

1. Choose a category.
2. Choose a file or drag it into the app.
3. Select the output format.
4. Choose the output folder.
5. Click Convert.

SETUP DETAILS

Setup keeps official Python 3.14.7, the complete pinned PySide6-Essentials, Pillow, pillow-heif, and py7zr dependency set, FFmpeg, FFprobe, settings, and app-specific files private to this folder. It does not require administrator access, change PATH, or install global Python packages. Downloaded runtime archives are verified before use.

Setup creates and validates a folder-local File Converter shortcut that starts the app directly with this folder's private runtime. Run Installer.bat again to repair setup or after moving the complete folder. Your files are never changed by setup.

PRIVACY AND REMOVAL

The app has no telemetry, analytics, advertisements, accounts, uploads, or runtime network requests. Files are processed locally. Temporary archive staging stays in .runtime\work inside the extracted folder and is removed after each job; a later startup safely retries cleanup after an interrupted job. Review setup.log before sharing because it can contain local folder paths.

To remove this tool, close it and delete the extracted folder. This removes its folder-local shortcut, private runtime, dependencies, settings, and app files.

TROUBLESHOOTING

If setup or the shortcut fails, review setup.log and run Installer.bat again. Success is shown only after the dependencies, offline self-tests, and shortcut all pass. Keep the complete extracted folder together.

The original input is never overwritten. BAT/CMD and PY/PYW conversions only change the extension and do not translate script contents.
